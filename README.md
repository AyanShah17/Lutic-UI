# Lutic — Intelligence in motion

Responsive AI engineering studio website. No dependencies or build step.

## Run locally

```sh
python3 -m http.server 8000
```
Open http://localhost:8000. Alternatively open index.html directly.

## Design
Editorial typography, acid-lime accents, procedural particle sphere, scroll reveals, pointer-reactive service cards, responsive navigation and reduced-motion support. Original implementation in HTML, CSS and JavaScript; no third-party design-kit components are bundled.

The agent orchestrator is a simulated demo, not a live AI system. The contact form downloads a local brief; connect a verified contact endpoint before launch. Browser and accessibility testing are still required.
