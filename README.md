# Lutic — AI that works. In the real world.

Responsive AI engineering company website. Serve with `python3 -m http.server 8000` and open http://localhost:8000.

## Motion and design
GSAP 3.13.0, ScrollTrigger and Lenis 1.3.11 are loaded from version-pinned jsDelivr URLs. Native scroll and CSS reveal fallbacks remain available when external scripts fail; reduced-motion preferences disable the enhanced animation. The visual direction uses original editorial composition, architectural diagrams and product-interface-inspired cards, informed by public UI inspiration patterns. No proprietary Mobbin or Dribbble assets are bundled.

## Launch limitations
Browser, accessibility and performance tests remain outstanding. The workflows are illustrative simulations, not customer case studies or live AI systems. The contact form creates a local brief and does not transmit data. Production should self-host reviewed dependency assets or add verified integrity metadata and a real contact endpoint.
